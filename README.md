# ЦПМ для учителей — демоверсия

Статический сайт для GitHub Pages. **Неофициальный прототип**, визуально вдохновлённый сайтом ЦПМ, без использования официального логотипа. Все 30 курсов, цены и описания вымышлены.

## Публикация
1. Создайте публичный репозиторий на GitHub.
2. Загрузите `index.html`, `program.html`, `style.css`, `app.js`, `program.js`, `courses.json` в корень.
3. В Settings → Pages выберите Deploy from a branch → main → /(root).
4. Откройте опубликованную ссылку.

## Проверка локально
Запустите `python -m http.server 8000` и откройте `http://localhost:8000`. При открытии файла двойным щелчком загрузка JSON может блокироваться браузером.

## Как работает
Поиск локальный: тематические словари, совпадения с описаниями и учёт аудитории. Это не языковая модель. Анимация подсказки ничего не вводит в поле и останавливается, когда пользователь начинает писать. Чат сохраняется только до обновления страницы. Данные не отправляются на сервер.

## Страницы курсов и запись
Каждая рекомендация ведёт на `program.html?id=DEMO-001` (ID зависит от курса). На странице показаны описание, аудитория, длительность и условная цена. Кнопка «Записаться на курс» **только демонстрирует сценарий** и не принимает персональные данные, не создаёт заявку и не ведёт на настоящий курс.

Для подключения реального каталога замените тестовые записи в `courses.json` на разрешённые к публикации данные и добавьте официальный URL регистрации в поле `registration_url`. Затем настройте кнопку на переход по проверенному URL. Не подставляйте вымышленные ссылки и не публикуйте закрытые данные.
