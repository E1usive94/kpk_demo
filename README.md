# НИТИ · Навигатор образовательных решений (демо)

Статический сайт на HTML/CSS/JavaScript с **30 полностью вымышленными курсами** из `courses.json`. Не использует реальные данные ЦПМ. Никаких API-ключей и сервера не требуется.

## Публикация на GitHub Pages

1. Создайте **публичный** репозиторий на GitHub, например `niti-navigator-demo`.
2. Загрузите **содержимое** этой папки в корень репозитория: `index.html`, `style.css`, `app.js`, `courses.json`, `README.md`.
3. В репозитории откройте **Settings → Pages → Build and deployment**.
4. Выберите **Deploy from a branch**, затем ветку `main`, папку `/(root)` и нажмите **Save**.
5. После публикации ссылка будет вида `https://ВАШ-ЛОГИН.github.io/niti-navigator-demo/`.

## Проверка локально

В папке проекта выполните `python -m http.server 8000` и откройте `http://localhost:8000`.

Не запускайте `index.html` двойным кликом как `file://`: браузер может заблокировать загрузку JSON.

## Как устроен подбор

Это **демонстрационный поиск по смысловым темам и ключевым фрагментам слов**, а не настоящий LLM/векторный поиск. Система определяет темы пользовательского запроса, сопоставляет их с названием, тегами, описанием и аудиторией курсов, ранжирует результаты и показывает причины рекомендаций. Никакие запросы на сервер не отправляются.

Для настоящего ИИ потребуется отдельный backend с защищённым API-ключом и проверка качества рекомендаций. Не публикуйте API-ключ в JavaScript или репозитории.

## Замена курсов

Меняйте `courses.json`, сохраняя поля `id`, `title`, `category`, `audience`, `level`, `duration_hours`, `price_rub`, `description`, `learning_outcome`, `tags`. Данные в публичном репозитории доступны всем.
